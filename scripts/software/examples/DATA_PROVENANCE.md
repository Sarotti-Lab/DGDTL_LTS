# Example data provenance

The curated examples are validated benchmark partitions retained from the
scientific research workspace. Their scientific descriptions and literature
citations are in the immutable supplementary source:

| Example | Scientific context | Source citation key in SI |
| --- | --- | --- |
| D01 | chiral anion phase-transfer enantioselectivity | `orlandi_mechanistic_2017` |
| D02 | Diels–Alder activation-energy proof of concept | `perez_low-cost_2025` |
| D08 | constrained NCB-stability control based on D07 | `platt_2025` |
| D11 | palladium Suzuki cross-coupling site selectivity | `niemeyer_2016`, `cao_2025` |
| S03 | fixed synthetic multiple-regression sentinel | project-generated benchmark; no external source |

The release preserves these partitions for reproducibility of the certified
examples. Before a public Capa 2 distribution, the maintainers must confirm
that the provenance and redistribution conditions for every included dataset
permit that release. No third-party dataset licence is inferred or changed by
the MIT software licence.
